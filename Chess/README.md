# 国际象棋（Chess）

一个用 C# / .NET 10 + Windows Forms 编写的完整国际象棋程序，棋子使用 Unicode 国际象棋字符绘制。
用 Visual Studio 2026 打开 `Chess.slnx` 即可直接编译运行（F5）。

## 界面

整个程序只有**一个窗口**：主菜单、难度选择、对局 / 回放都在同一个窗口里切换，不会再弹新窗口。
窗口可以自由缩放、最大化，棋盘与侧栏会随窗口大小自动排布（缩放时棋子、坐标、按钮一起适配）。

主菜单包含三个入口：

| 按钮 | 说明 |
| --- | --- |
| 双人对战 | 同一台电脑上两人轮流走棋 |
| 人机对战 | 先选择难度，再进入对局 |
| 导入对局 | 打开一个 `.rcd` 棋谱，进入只读回放 |

## 功能

### 人机对战难度

| 难度 | 搜索深度 | 思考上限 | 说明 |
| --- | --- | --- | --- |
| 简单 | 2 层 | 0.5 秒 | 有 45% 概率随机走子，会漏着 |
| 普通 | 4 层 | 1.8 秒 | 能算清常见捉子兑子 |
| 困难 | 6 层（迭代加深） | 4.5 秒 | Alpha-Beta + 静态搜索 + 走法排序 |

### 规则

马/象/车/后/王的走法、兵首步两格、吃过路兵、王车易位（含被将军、路过被攻击的限制）、
兵升变（可升后/车/象/马）、将军与将杀、逼和、五十步规则、三次重复局面、子力不足自动和棋。不计时。

### 对局界面

点击棋子高亮显示所有合法落点，深色圆点表示空位、圆环表示可吃子；被将军的王格标红。
右侧显示模式、状态、棋谱列表与「悔棋 / 新对局 / 返回」。

- 任何一方走子，棋子都会从起点**滑行**到终点（易位时王和车一起滑，约 0.28 秒，缓入缓出、途中略微放大）。
- 被吃掉的棋子不会立刻消失，会一直留在原位，等吃子的棋子滑到它身上才被吃掉（吃过路兵、回放后退同样处理）。
- 轮到电脑时，会先固定**等待 3 秒**再落子（搜索与这 3 秒并行进行，所以困难难度不会额外叠加等待）。
  等待期间状态栏显示「电脑思考中…」，这时也可以直接点「返回」离开。

### 导入回放

「导入对局」读取任意 `.rcd`（PGN 格式）文件并回放：
- **点击棋谱里的任意一手**，棋盘立刻跳转到该手走完后的局面（左列白方、右列黑方，点哪边走哪边）；
- 跳转不是逐手重放：程序先把目标局面一次算好，再让所有位置有变化的棋子同时滑过去（约 0.28 秒）；
- **上一步 / 下一步** 逐手查看，也可以按 `←` `→` 方向键；
- **自动 / 暂停** 定时连续播放（快捷键空格）；
- 当前这一手所在的行会高亮，该手的着法用金色强调，棋盘同时标出上一步的起点终点；
- 标题栏与侧栏显示该局的对局模式。

解析时会自动跳过 `{注释}`、`;` 行注记、`$1` 之类的 NAG 记号，兼容 `0-0` / `O-O` 两种易位写法。

### 棋谱记录

每一局都会在**程序所在目录**的 `Records\` 文件夹里生成 `.rcd` 文件，
文件名是开始对局的时间戳，形如 `2026_05_20_1.rcd`（日期 + 当天流水号），内容为标准 PGN。

模式标记写在 `[Mode "n"]` 标签里：

| 值 | 含义 |
| --- | --- |
| 0 | 双人对战 |
| 1 | 人机对战（简单） |
| 2 | 人机对战（普通） |
| 3 | 人机对战（困难） |

没有 `Mode` 标签的旧棋谱，导入时按**双人对战**处理。示例：

```
[Event "人机对战（普通）"]
[Site "Chess · 本地对局"]
[Date "2026.10.17"]
[Round "1"]
[White "玩家"]
[Black "电脑（普通）"]
[Result "0-1"]
[Mode "2"]
[TimeControl "-"]
[Termination "将杀"]

1. e4 e5 2. Nf3 Nc6 3. Bb5 Nf6 4. O-O Be7 0-1
```

## 代码结构

```
Chess/
├── Program.cs                 入口
├── MainForm.cs                主窗口外壳（页面切换、导入、窗口图标）
├── MainMenuView.cs            主菜单页
├── DifficultyView.cs          难度选择页
├── GameView.cs                对局页 / 导入回放页
├── PromotionDialog.cs         升变选择小对话框
├── app.ico                    应用图标
├── Core/
│   ├── Piece.cs               棋子编码与 Unicode 字符
│   ├── Move.cs                走法结构
│   ├── Board.cs               棋盘、走法生成、攻击判定、走子/撤销、FEN
│   ├── San.cs                 标准代数记谱（SAN）生成，含消歧
│   └── GameSession.cs         一局棋的状态与全部规则判定
├── Ai/
│   ├── Evaluator.cs           局面评估（子力 + 位置表 + 兵形）
│   └── AiEngine.cs            Alpha-Beta 搜索、静态搜索、难度配置
├── Recording/
│   ├── PgnRecorder.cs         PGN 棋谱写入、文件命名、Mode 标签
│   └── PgnImporter.cs         PGN 解析、SAN 走法匹配、导入模型
└── Ui/
    ├── Theme.cs               配色与字体
    ├── UiMetrics.cs           DPI 换算（控件尺寸按 DeviceDpi 缩放）
    ├── PieceRenderer.cs       棋子绘制（字符轮廓填充 + 描边）
    ├── BoardView.cs           棋盘控件
    └── RoundedButton.cs       圆角按钮
```

走法生成的正确性已用 perft 测试校验（初始局面、Kiwipete 等 5 个标准测试局面，深度 1–4 全部吻合）；
棋谱的写入与读回也做了往返一致性校验。

## 说明

- 棋盘上的白方棋子用实心字符 ♚♛♜♝♞♟ 以白色填充、黑方以深色填充，再各加一圈对比描边，
  这样在浅色格和深色格上都清晰可辨；菜单与升变对话框直接用彩色 Unicode 棋子字符显示。
- 坐标 a–h / 1–8 使用小号、半透明字体，不会喧宾夺主。
- 布局使用手动 DPI 换算（`UiMetrics`），在 100% / 150% / 200% 缩放下比例一致。
- 棋谱文件使用 UTF-8（带 BOM）编码，方便记事本直接查看中文标签。
